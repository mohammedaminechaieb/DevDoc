AutoGen is Microsoft's open-source framework for building multi-agent AI applications. AutoGen v0.4 (the current generation, also called AutoGen AgentChat) is a complete redesign from v0.2, introducing an async-first architecture, a layered API, and a new agent communication model. The core design principle of AutoGen v0.4 is composability. The framework is split into three layers: the Core layer (low-level agent messaging and runtime primitives), the AgentChat layer (high-level team-based patterns with preset agents), and the Extensions layer (integrations with external tools and services). Install AutoGen v0.4 with: pip install autogen-agentchat autogen-ext[openai]. The framework requires Python 3.10+. AutoGen v0.4 is async-first. All agent interactions are async by default, using Python's asyncio. This makes AutoGen well-suited for I/O-heavy applications with many concurrent tool calls or external API requests. === ag_core | core | BaseAgent,Runtime ===
The AutoGen Core layer provides the foundational primitives for building multi-agent systems: the agent interface (BaseAgent), the message protocol, and the runtime (SingleThreadedAgentRuntime and distributed variants). Agents in the Core layer implement the BaseAgent interface and communicate through typed messages. The runtime manages agent lifecycle, message routing, and subscription. This is a publish-subscribe model — agents subscribe to message types and receive messages that match their subscription. ```python from autogen_core import BaseAgent, MessageContext from autogen_core import SingleThreadedAgentRuntime from dataclasses import dataclass @dataclass class TextMessage: content: str sender: str class MyAgent(BaseAgent): async def on_message(self, message: TextMessage, ctx: MessageContext) -> None: print(f"Received from {message.sender}: {message.content}") # reply await self.publish_message(TextMessage(content="Got it!", sender=self.id.key)) runtime = SingleThreadedAgentRuntime() await MyAgent.register(runtime, "my_agent", lambda: MyAgent()) await runtime.start() await runtime.send_message(TextMessage(content="Hello", sender="user"), recipient=AgentId("my_agent", "default")) await runtime.stop() ``` The runtime handles concurrency, message delivery, and shutdown lifecycle. === ag_groupchat | groupchat | GroupChat ===
AutoGen AgentChat provides two primary team patterns for multi-agent collaboration: RoundRobinGroupChat and SelectorGroupChat. RoundRobinGroupChat cycles through agents in a fixed order. Each agent receives all prior messages and responds in turn. The team runs for a fixed number of turns or until a termination condition is met. ```python from autogen_agentchat.agents import AssistantAgent from autogen_agentchat.teams import RoundRobinGroupChat from autogen_agentchat.conditions import TextMentionTermination agent1 = AssistantAgent("critic", model_client=client, system_message="Critically evaluate ideas.") agent2 = AssistantAgent("defender", model_client=client, system_message="Defend the idea against criticism.") termination = TextMentionTermination("FINAL ANSWER") team = RoundRobinGroupChat( participants=[agent1, agent2], termination_condition=termination, max_turns=10, ) result = await team.run(task="Should we adopt microservices architecture?") ``` SelectorGroupChat uses an LLM to decide which agent speaks next. === ag_tools | tools | FunctionTool ===
AutoGen agents use tools to interact with external systems. In AutoGen v0.4, tools are defined using the FunctionTool wrapper or as Python callables that the framework auto-wraps. ```python from autogen_core.tools import FunctionTool def search_web(query: str) -> str: """Search the web and return the top result.""" # implementation return f"Top result for '{query}': ..." async def get_stock_price(ticker: str) -> float: """Get the current stock price for a ticker symbol.""" # async implementation return 150.75 search_tool = FunctionTool(search_web, description="Search the web") stock_tool = FunctionTool(get_stock_price, description="Get stock price") agent = AssistantAgent( name="financial_analyst", model_client=client, tools=[search_tool, stock_tool], system_message="Use tools to find accurate financial information.", ) ``` FunctionTool automatically extracts the tool schema from the function signature and docstring. === ag_agentchat | agentchat | AgentChat ===
AutoGen AgentChat provides a high-level API for building conversational multi-agent applications. The main abstractions are: agents (AssistantAgent, UserProxyAgent, CodeExecutorAgent, SocietyOfMindAgent), teams (RoundRobinGroupChat, SelectorGroupChat, Swarm), termination conditions, and UI components. AssistantAgent is the most commonly used agent. It wraps an LLM client, maintains a message history, and can use tools. Its system_message parameter sets the agent's persona and instructions. Swarm is a special team type for hand-off patterns. Agents in a Swarm can transfer control to each other using a HandoffMessage. This is useful for routing conversations between specialists without a central orchestrator. ```python from autogen_agentchat.teams import Swarm from autogen_agentchat.messages import HandoffMessage triage_agent = AssistantAgent( "triage", model_client=client, handoffs=["billing", "technical"], system_message="Route to billing or technical based on the user's issue." ) billing_agent = AssistantAgent("billing", model_client=client, handoffs=["triage"]) technical_agent = AssistantAgent("technical", model_client=client, handoffs=["triage"]) swarm = Swarm([triage_agent, billing_agent, technical_agent], default_active_agent="triage") result = await swarm.run(task="My invoice is incorrect.") ``` The Console utility streams agent messages to
