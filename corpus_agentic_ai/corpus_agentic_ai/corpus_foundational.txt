ReAct (Reasoning + Acting) is a prompting paradigm introduced by Yao et al. (2022) that combines chain-of-thought reasoning with action taking in a unified loop. Rather than separating thinking from doing, ReAct interleaves reasoning traces and actions in a single sequence, allowing the agent to reason about which action to take, take it, observe the result, and continue reasoning. The ReAct format alternates between three types of steps: Thought (the agent reasons about its current situation and what to do next), Action (the agent calls an external tool or takes an action), and Observation (the result of the action). This Thought-Action-Observation loop repeats until the agent has enough information to produce a final answer. Chain-of-Thought (CoT) prompting is a technique introduced by Wei et al. (2022) that improves large language model performance on complex reasoning tasks by encouraging the model to produce step-by-step reasoning rather than jumping directly to an answer. CoT emerged from the observation that large language models (GPT-3, PaLM) trained on text naturally produce reasoning steps when prompted to, and that these intermediate steps significantly improve final answer accuracy. The standard few-shot CoT approach provides exemplars in the prompt that demonstrate the desired reasoning format: a question, a chain of reasoning steps, and a final answer. The model then imitates this format for new questions. Example CoT prompt and completion: Question: Roger has 5 tennis balls. He buys 2 more cans of tennis balls. Each can has 3 tennis balls. === concept_reflexion | reflexion | Reflexion ===
Reflexion (Shinn et al., 2023) is a framework for giving AI agents verbal reinforcement through linguistic feedback. Where standard reinforcement learning updates model weights using scalar rewards, Reflexion stores reflective text summaries in the agent's memory and uses them to guide future attempts at the same task. The key insight of Reflexion is that large language models already have a strong ability to reason about their own failures — if you show them what went wrong, they can generate useful feedback. Rather than training a separate reward model or doing gradient updates, Reflexion uses the LLM itself to reflect on its failures and generate improvement strategies. The Reflexion loop has three components: an Actor (the agent that generates actions), an Evaluator (which scores the agent's output — this can be a heuristic, a test suite, or another LLM), and the Self-Reflection module (which generates verbal feedback from the evaluation signal).
