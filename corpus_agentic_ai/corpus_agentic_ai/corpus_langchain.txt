=== lc_rag | rag | RAGChain ===
LangChain is the most popular framework for building Retrieval-Augmented Generation (RAG) pipelines. === lc_memory | memory | ConversationMemory ===
LangChain provides several memory implementations for maintaining conversation history in chat applications. Memory components store past interactions and inject them into the prompt for future calls. ConversationBufferMemory stores the full conversation history as a list of messages. It is simple but can exceed the LLM's context window for long conversations. ConversationBufferWindowMemory keeps only the last k exchanges. This bounds the context length at the cost of forgetting older context. ConversationSummaryMemory uses an LLM to summarize the conversation history. When the buffer exceeds a threshold, the oldest messages are summarized and replaced with the summary. This is memory-efficient but introduces summarization latency. ConversationSummaryBufferMemory combines buffering and summarization. Recent messages are kept in full; older messages are summarized. ```python from langchain.memory import ConversationBufferWindowMemory from langchain.chains import ConversationChain memory = ConversationBufferWindowMemory(k=5, return_messages=True) chain = ConversationChain(llm=ChatOpenAI(), memory=memory, verbose=True) chain.predict(input="My name is Alice.") chain.predict(input="What is my name?") # Output includes "Alice" from memory ``` For

=== rag_text_split | text_splitting | TextSplitter ===
Text splitting is one of the most impactful decisions in a RAG pipeline. The goal is to create chunks that are semantically coherent (each chunk covers one idea), consistently sized (predictable token counts for the LLM), and have sufficient overlap (context is preserved across chunk boundaries). LangChain's RecursiveCharacterTextSplitter is the recommended default. It splits on a hierarchy of separators: first tries to split on paragraph breaks, then sentence breaks, then word breaks. This preserves semantic units as much as possible. ```python from langchain_text_splitters import RecursiveCharacterTextSplitter splitter = RecursiveCharacterTextSplitter( chunk_size=1000, # characters (not tokens — be aware of model limits) chunk_overlap=200, length_function=len, # or use tiktoken for token-accurate splitting add_start_index=True, # adds metadata.start_index to each chunk ) # For token-accurate splitting with OpenAI models: from langchain_text_splitters import TokenTextSplitter token_splitter = TokenTextSplitter( encoding_name="cl100k_base", # GPT-4o tokenizer chunk_size=512, # tokens chunk_overlap=50, ) ``` Specialised splitters: MarkdownTextSplitter splits on markdown headings, preserving document structure.
